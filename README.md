# check-spy-app / ExeRouteMonitor

ابزار آزمایشی Windows 11 برای بررسی ارتباط‌های یک EXE با مسیر دقیق و تولید گزارش محدود از شواهد شبکه. اتصال به یک سرور یا ثبت مشخصات در لاگ محلی، به‌تنهایی اثبات ارسال اطلاعات شخصی یا رفتار مخرب نیست.

## وضعیت تازه: آزمون TLS سمت برنامه ناموفق بود
گزارش بعدی کاربر برای نسخه ۲٫۶ یک شکست TLS سمت کلاینت و صفر درخواست HTTP خوانا داشت. نصب و پاک‌سازی CA، توقف پروکسی و حذف مواد خصوصی طبق گزارش تأیید شدند؛ این اثبات pinning یا ایمنی همه سناریوهای Windows نیست. برای همین WoW آزمون CA را تکرار نکنید. مسیر فعلی [بررسی رسمی و درخواست داده](docs/research/OFFICIAL-DIAGNOSTICS-fa.md) است، نه دورزدن حفاظت برنامه.

## شروع
- کد فعلی: [`app/`](app/)
- راهنمای کامل مرحله جدید: [`app/TLS-TEST-fa.md`](app/TLS-TEST-fa.md)
- آزمون قبلیِ آزمایشی TLS (برای این پرونده فعلاً تکرار نشود): `app\Start-TLS-Test.cmd` با دوبار کلیک معمولی، **نه با ادمین**.
- پاک‌سازی گواهی‌های همین ابزار: `app\Cleanup-TLS.cmd` با همان حساب معمولی.
- مانیتور قدیمی شبکه: `app\Start.cmd` (برای Pktmon نیازمند دسترسی ادمین؛ خود هدف نباید با ادمین اجرا شود).
- تحلیل فقط‌خواندنی فایل: `app\Start-Diagnostics.cmd`.
- آزمون عبور بدون گواهی: `app\Start-Proxy-Test.cmd`.

نسخه قابل‌حمل رسمی mitmdump در Git نگهداری نمی‌شود. در checkout تازه، شروع TLS با تأیید کاربر آن را از منبع رسمی دریافت و SHA256 بسته و فایل را بررسی می‌کند. دریافت ابزار هیچ گواهی نصب نمی‌کند. مجوز و سابقه اعتبارسنجی انتشار در `app/tools/mitmproxy/` هستند.

## هشدار مهم نسخه ۲٫۶
این نسخه **آزمایشی** است، نه ابزار امنیتی production-ready. بازرسی فقط برای `telemetry-in.battle.net:443` و SNI دقیق همان دامنه طراحی شده؛ ارتباط حساب، سایر دامنه‌ها و پروتکل اختصاصی بازی رمزگشایی نمی‌شوند. CA موقت فقط پس از تأیید جداگانه در CurrentUser Root وارد می‌شود، اما اعتماد CA در حساب ویندوز از نظر دامنه گسترده است؛ محدودیت دامنه را پروکسی اعمال می‌کند. `ssl_insecure=false` باقی می‌ماند و رد گواهی/pinning دور زده نمی‌شود.

حذف CA و توقف پروکسی در پایان بررسی می‌شوند. محافظ مستقل زمان‌دار و recovery موجودند، اما خاموشی یا بسته‌شدن هم‌زمان فرایندها می‌تواند مانع حذف شود؛ در آن حالت `Cleanup-TLS.cmd` را اجرا کنید. بازی خودکار کشته نمی‌شود. اجرای گواهی، ACL، انتساب PID و WinForms روی Windows 11 در محیط توسعه آزمون زنده نشده‌اند.
