# check-spy-app / ExeRouteMonitor

ابزار آزمایشی Windows 11 برای بررسی محلی ارتباط‌های یک EXE با مسیر دقیق. اتصال به سرور یا ثبت مشخصات در لاگ محلی، اثبات خودکار ارسال آن مشخصات یا رفتار مخرب نیست.

## نسخهٔ فعلی: ۲٫۷ — ارتقای همان مانیتور
به درخواست کاربر، مسیر فعلی مانیتورینگ یکپارچه است، نه تکرار آزمون CA یا جایگزینی با درخواست دادهٔ رسمی.
- اجرا: **app\Start.cmd**، با Run as administrator برای Pktmon. خود هدف با دسترسی معمولی اجرا می‌شود.
- راهنمای ساده: [QUICK-START-fa.md](app/QUICK-START-fa.md).
- گزارش تازه: **UnifiedReport-….json**؛ مقصدها، شمارندهٔ رفت‌وبرگشت، شواهد خوانای خروجی و دسته‌بندی لاگ‌های محلی همان اجرا.
- جریان ساده گواهی نصب نمی‌کند، پروکسی را تغییر نمی‌دهد و کلید TLS درخواست نمی‌کند. محتوای رمزگذاری‌شده **نامعلوم** باقی می‌ماند.
- شمارنده‌ها payload مشاهده‌شده‌اند، نه حجم یکتای دادهٔ شخصی. انتساب tuple/زمان و پوشش مقصدها محدودیت دارند.
- آزمون‌های انجام‌شده و محدودیت Windows: [QA-v2.7](app/tests/QA-v2.7.md).

checkout شامل کد و راهنماست، نه نصب‌کنندهٔ آفلاین یا EXE مستقل کامپایل‌شده. tools قبلی در به‌روزرسانی حفظ شود؛ ابزار نصب‌نشده پس از تأیید از منبع رسمی دریافت و اعتبارسنجی می‌شود.

## ابزار کمکی جدید: بررسی آفلاین ETW — ۲٫۶٫۵

این ابزار مستقل، جایگزین یا کاهش نسخهٔ مانیتور ۲٫۷ نیست؛ برای بررسی ساختار فایل‌های ضبط‌شدهٔ WinHTTP/WinINet اضافه شده است.
- اجرا بدون ضبط تازه: [Inspect-ETW-Fields.cmd](tools/etw-field-inspector-v2.6.5/Inspect-ETW-Fields.cmd)، با همان حساب ویندوزی ضبط قبلی.
- [راهنمای فارسی](tools/etw-field-inspector-v2.6.5/START-HERE-fa.md) و [وضعیت آزمون‌ها](tools/etw-field-inspector-v2.6.5/QA.md).
- ورودی محلی: ETL به‌همراه فایل انتساب پردازش همان نشست، یا private-target-events.jsonl از ضبط سازگار قبلی؛ گزارش عمومی JSON ورودی نیست.
- خروجی EventFieldReport فقط ساختار فیلدها، طول‌ها، شمارنده‌ها و نشانه‌های محدود URL/API را دارد؛ مقدار خام، مسیر کامل URL، توکن، هدر و بدنه صادر نمی‌شوند. گزارش را پیش از اشتراک بازبینی کنید.
- هیچ فایل ضبط واقعی یا گزارش خصوصی در این به‌روزرسانی منتشر نشده است. ابزار TLS را رمزگشایی نمی‌کند؛ نشانهٔ URL/API اثبات ارسال نیست.
- ۲۴ آزمون مصنوعی موفق؛ اجرای واقعی Windows PowerShell 5.1 و ETL کاربر هنوز آزموده نشده است.

## ساخت و آزمون ویندوز در GitHub Actions

[راهنمای آزمون ویندوز](docs/WINDOWS-CI-fa.md): آزمون‌های مصنوعی روی Windows Server 2022 با PowerShell 5.1 و 7 و ساخت ZIP ابزار مستقل، فقط پس از موفقیت آزمون‌ها. این گردش‌کار اجرای بازی، ضبط زنده یا بازیابی بدنه/URL کامل HTTPS را تأیید نمی‌کند. تا دریافت نتیجهٔ Actions، اجرای واقعی ویندوز تأییدنشده است.

## مراحل قبلی و گواهی
آزمون TLS نسخهٔ ۲٫۶ یک شکست TLS سمت کلاینت و صفر درخواست HTTP خوانا داشت؛ علت قطعی/pinning اثبات نشد. برای این پرونده آن آزمون را تکرار نکنید. فایل‌های TLS/Proxy قدیمی که در مخزن مانده‌اند **تاریخی/آزمایشی و خارج از مسیر پیش‌فرض ۲٫۷** هستند. Cleanup-TLS.cmd برای پاک‌سازی دستی آثار قبلی است؛ این نسخه خودکار پروکسی/CA از قبل موجود را پاک نمی‌کند.
[بررسی رسمی و درخواست داده](docs/research/OFFICIAL-DIAGNOSTICS-fa.md) فقط مرجع تکمیلی است، نه جایگزین خواستهٔ فعلی.

## ادامهٔ جلسه: WoW Retail تا ۰٫۱۸
[checkpoint جاری، گراف و راهنمای ادامه](docs/session/retail-updater-v0.18/README-fa.md) شامل sourceهای ۰٫۱۰ تا ۰٫۱۸، خلاصهٔ پاک‌سازی‌شدهٔ آزمون‌ها، پیشروی صف، مکث/ادامهٔ همان دسته و Range بزرگ‌تر است. این‌ها staging هستند؛ نصب CASC/updater کامل هنوز پیاده نشده است. مانیتور ۲٫۷ و checkpointهای قبلی حفظ شده‌اند. انتقال رونوشت خام چت یا داده‌های خصوصی نیست.

## checkpoint تاریخی: WoW Retail تا ۰٫۹
[checkpoint جدید و گراف](docs/session/retail-updater-v0.9/README-fa.md) شامل تاریخچهٔ جامع، کدهای موجود ۰٫۱ تا ۰٫۹، نتیجه‌های پاک‌سازی‌شده و کار باقی‌مانده است. دریافت نمونه‌های آرشیوی موفق بوده؛ نصب CASC و به‌روزرسان کامل پیاده نشده‌اند. در آن checkpoint، ۰٫۱۰ فقط درخواست/بررسی اولیه بود. این انتقال رونوشت کامل خام چت نیست؛ [پوشش دقیق](docs/session/retail-updater-v0.9/COVERAGE-fa.md) را بخوانید.
