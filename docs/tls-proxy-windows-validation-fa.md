# نتیجهٔ تست واقعی پروکسی روی ویندوز

تست واقعی HTTPS روی Windows Server 2022 در GitHub Actions موفق شد. هفت حالت شامل ارتباط سالم، گواهی نامعتبر سمت برنامه، قطع اتصال هنگام دست‌دهی، انتساب فرایند اشتباه، تونل دامنهٔ خارج از محدوده، ثبت خصوصی URL/بدنهٔ ساختگی و گواهی نامعتبر سرور بررسی شدند.

اجرای موفق: https://github.com/kokononox/check-spy-app/actions/runs/38390727501

کد بررسی‌شده: `c7ae4f4f9ed8889877274435740be1c651b1aab5`

فقط داده، سرور، کلاینت و گواهی ساختگی استفاده شد. هیچ فایل بازی، گزارش کاربر، هش فایل بازی، اطلاعات حساب یا کلید نشست کاربر به مخزن یا Actions فرستاده نشد. گواهی سیستم نصب نشد؛ اعتماد فقط با فایل CA داخل فرایندهای آزمایشی تنظیم شد. عکس وضعیت CurrentUser Root قبل و بعد یکسان بود.

این نتیجه می‌گوید پروکسی و تشخیص خطا در شرایط ساختگی روی ویندوز کار می‌کنند. **نه علت خطای بازی مشخص شده، نه URL یا بدنهٔ واقعی بازی به دست آمده است.** مسیر نصب/حذف گواهی در رابط کاربری هم در این تست بررسی نشده است.

برای این مرحله اجرای دوبارهٔ بازی از کاربر خواسته نمی‌شود. موفقیت localhost جای تأیید رفتار بازی را نمی‌گیرد و قطع TLS به‌تنهایی مدرک pinning نیست.
