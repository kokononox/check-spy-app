## نتیجهٔ آخر
در آزمون کاربر، دستهٔ هشت‌تایی نسخهٔ ۰٫۹ با ۵۱۱۱ بایت پاسخِ دادهٔ بازی کامل شد؛ صحت کدگذاری و CKey بازشدهٔ هر هشت نمونه تأیید شد. نصب بازی تغییر نکرد. این فقط نمونه‌های کوچک است، نه کل به‌روزرسانی.[^https://github.com/kokononox/check-spy-app/blob/main/docs/session/retail-updater-v0.9/EVIDENCE-SUMMARY.json]

## وضعیت واقعی
- TLS تلمتری هنوز رمزگشایی نشده و ارسال فیلدهای مشخص CPU/GPU/RAM اثبات نشده است.
- مسیر دریافت دقیق اشیا از بخش آرشیو با HTTP Range برای نمونه‌های آزموده‌شده کار کرده است.[^https://github.com/kokononox/check-spy-app/blob/main/docs/session/retail-updater-v0.9/EVIDENCE-SUMMARY.json]
- نسخهٔ ۰٫۱۰ فقط در مرحلهٔ برنامه‌ریزی/بررسی منبع است؛ کد، بسته یا نتیجهٔ اجرای آن هنوز تولید نشده است.
- هیچ CASC writer، نصب کامل، patch chain، rollback یا نسخهٔ به‌روزشدهٔ قابل بازی تأیید نشده است.

مانیتور ۲٫۷ موجود در ریشه، محصول قبلی است. snapshotهای Retail این پوشه آن را جایگزین نمی‌کنند. فایل‌های بازی، vendor باینری، داده‌های خصوصی و متن خام گفتگو عمداً در Git عمومی قرار نگرفته‌اند.
