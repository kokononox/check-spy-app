# پوشش انتقال

## ثبت شد
- کد و فایل‌های متنی دقیق بسته‌های تحویل‌شدهٔ ۰٫۱۰ تا ۰٫۱۸؛ manifest و TEST-RESULTS هر بسته حفظ شده است.
- تاریخچهٔ فنی، تصمیم‌ها، مرز ادعاها و خلاصهٔ allowlist گزارش‌های واقعی تا آخرین آزمون ۰٫۱۸.
- گراف Mermaid قابل ویرایش، HTML آفلاین و دادهٔ گراف.
- آزمون‌های توسعهٔ تاریخیِ موجود محلی، فقط اگر بازیابی شده‌اند؛ این‌ها الزاماً portable یا CI-ready نیستند.

## عمداً منتشر نشد
رونوشت لفظ‌به‌لفظ گفتگو، pasted chat، خام JSONهای کاربر، PCAP/ETL، لاگ خصوصی، مسیرهای سیستم کاربر، حساب/توکن/شناسه‌های جلسه، کلیدها، فایل‌های واقعی بازی/CDN، SQLite و state خصوصی. SessionFile ID یا لینک داخلی چت در اسناد عمومی نیست.

## نقص‌های پوشش آزمون
تمام کدِ بسته‌ها بازیابی شد؛ همهٔ فایل‌های test harness زمان ساخت در بستهٔ تحویل‌شده نبودند و فقط موارد باقی‌ماندهٔ workspace ضمیمه شده‌اند. فایل TEST-RESULTS گزارش تاریخی آزمون است، نه تضمین قابلیت اجرای suite از همین checkout. اسکریپت‌های تاریخی ممکن است مسیر ثابت /data و fixture/cache حذف‌شده داشته باشند. آزمون‌های Windows suite، قطع واقعی وسط پاسخ، power loss، CASC نصب و rollback از گزارش‌های این بخش قابل تأیید نیستند.

## حفظ گذشته
checkpoint تا ۰٫۹ و کد مانیتور ۲٫۷ تاریخی/مستقل حفظ می‌شوند. متن‌های تاریخی دربارهٔ «۰٫۱۰ هنوز ساخته نشده» مربوط به همان checkpoint قدیمی‌اند؛ وضعیت جاری در README این پوشه است. این انتقال «ذخیرهٔ کامل لفظ‌به‌لفظ جلسه» نامیده نمی‌شود.
