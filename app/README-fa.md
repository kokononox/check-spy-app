# ExeRouteMonitor 2.7

مانیتورینگ محلی یک EXE روی Windows 11. مسیر پیشنهادی: Start.cmd و دکمهٔ اصلی؛ بدون بازرسی TLS فعال.

راهنمای مرحله‌به‌مرحله: **QUICK-START-fa.md**. نتیجهٔ جدید: **UnifiedReport-….json**.

این بسته به‌روزرسانی سبک است؛ tools قبلی را حفظ کنید. پوشش همه مقصدها یا فهم همه محتوای رمزگذاری‌شده تضمین نمی‌شود. ابزار برای بررسی دفاعی برنامهٔ انتخاب‌شده است، نه اثبات خودکار جاسوسی.

فایل‌های PROXY/TLS/NEXT-STEP مربوط به مراحل تاریخی‌اند و مسیر پیش‌فرض نسخهٔ ۲٫۷ نیستند. آزمون CA قبلی برای این پرونده تکرار نشود.
