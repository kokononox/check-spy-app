# تغییرات نسخهٔ ۲٫۰

- تب Traffic / System data و بررسی شواهد خروجی
- بررسی رویدادهای Sysmon و نصب تازهٔ اختیاری فقط با باینری معتبرِ امضاشدهٔ Microsoft و تأیید کاربر؛ سیاست موجود جایگزین نمی‌شود
- ضبط اختیاری سراسری با Pktmon، تبدیل PCAPNG و ذخیرهٔ زمینهٔ اتصال‌ها
- تحلیل tshark با انتساب بر اساس tuple/زمان، تفکیک دادهٔ قابل‌خواندن و نامعلوم، و گزارش فیلدهای احتمالی سیستم
- تطبیق اختیاری شناسه‌های محدود محلی، بدون ذخیرهٔ مقادیر مبنا
- مسیر اختیاری SSLKEYLOGFILE با لانچر غیرادمین و بدون تغییر محیط سراسری
- ثبت هش‌های شواهد، User-Agent و پوشاندن مقدار query در گزارش
- آزمون‌های خودکار مصنوعی و بررسی نحو

این نسخه EXE مستقل ازپیش‌ساخته نیست؛ همهٔ فایل‌های اسکریپت باید کنار لانچر باقی بمانند. محدودیت‌ها و وضعیت آزمون در README-fa.md آمده است.
