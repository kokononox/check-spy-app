# Source snapshotهای Retail

نسخه‌های ۰٫۱ تا ۰٫۹ این جلسه برای تاریخچه/ادامهٔ توسعه ثبت شده‌اند؛ جایگزین app/Start.cmd مانیتور ۲٫۷ نیستند. نسخهٔ ۰٫۹ محدود به staging و دستهٔ کوچک است. هیچ نسخهٔ این پوشه updater نصب‌شوندهٔ کامل نیست.

README/TEST-RESULTS هر نسخه را بخوانید. historical-tests ثبت آزمون‌های موجود است و مسیرهای sandbox می‌تواند داشته باشد؛ CI بودن آن‌ها ادعا نمی‌شود. vendor باینریِ نسخهٔ ۰٫۲ و تمام فایل‌های بازی/داده‌های خصوصی عمداً حذف شده‌اند. تنها source و متن license/hash provenance منتقل شده است.

Checkpoint و گراف: [docs/session/retail-updater-v0.9](../../docs/session/retail-updater-v0.9/README-fa.md).

## ادامه تا ۰٫۱۸
snapshotهای source و متن دقیق بسته‌های ۰٫۱۰ تا ۰٫۱۸ به پوشه‌های v0.10 تا v0.18 اضافه شده‌اند؛ sourceهای قدیمی حذف یا جایگزین نشده‌اند. [checkpoint جاری](../../docs/session/retail-updater-v0.18/README-fa.md) و [پوشش](../../docs/session/retail-updater-v0.18/COVERAGE-fa.md) را بخوانید. تمام این نسخه‌ها staging/read-only نسبت به نصب بازی هستند، نه CASC installer. TEST-RESULTS تاریخیِ زمان ساخت با پذیرش محدود کاربر روی Windows فرق دارد. گراف و خلاصهٔ امن شواهد کنار checkpoint جدید است.
