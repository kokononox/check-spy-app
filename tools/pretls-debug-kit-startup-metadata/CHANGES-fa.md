# تغییرات ۰.۶ — آزمایشی

- ثبت خواندنی هویت فایل‌های EXE/loader و مقایسهٔ اختیاری با مبنا.
- بررسی مالک/نسل نخ رخداد و دسته‌بندی آدرس آغاز آن؛ قرینه، نه اثبات منشأ breakpoint.
- ثبت محدود زمینهٔ نخ جاری و حداکثر ۸ فریم با فرمان kv؛ پشتیبانی از ردیف‌های بدون شماره و شماره‌دار.
- خروجی امن allowlist؛ مسیر، آدرس، شناسهٔ نخ و stack خام خصوصی می‌مانند.
- اجرا یک‌بار قبل از ادامه؛ کنترل هم‌زمانی helperها در رابط.
- دروازهٔ ادامهٔ اولیه تغییر نکرده؛ هیچ عبور خودکار یا غیرفعال‌سازی حفاظت اضافه نشده است.
- آزمون Windows روی fixtureهای خود کیت؛ نه بازی، نه ارسال شبکه.
