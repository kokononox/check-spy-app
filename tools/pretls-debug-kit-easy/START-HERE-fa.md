# راه ساده — نسخهٔ آزمایشی ۰.۲

این نسخه رابط فارسی دارد؛ لازم نیست PowerShell باز کنی، دستور بنویسی یا PID وارد کنی.

## قبل از شروع، فقط یک‌بار

ویندوز ۶۴ بیتی و CDB x64 از Microsoft Debugging Tools لازم است. اگر از قبل نصب است، ابزار خودش پیدایش می‌کند. اگر نیست، فقط بخش Debugging Tools for Windows را از Windows SDK رسمی نصب کن:
https://learn.microsoft.com/en-us/windows-hardware/drivers/debugger/debugger-download-tools

CDB داخل این بسته نیست و چیزی خودکار دانلود نمی‌شود.

## کار تو

۱. ZIP را در یک پوشهٔ جدید استخراج کن؛ داخل ZIP اجرا نکن. روی **Start.cmd** دوبار کلیک کن.

۲. **«۱. انتخاب فایل EXE»** را بزن و فایل اصلی برنامهٔ مجاز را انتخاب کن. برنامه باید از قبل در محیط آزمایشی جداگانه، بدون حساب واقعی و بدون جلسهٔ آنلاینِ ضدتقلب، اجرا شده باشد. ابزار پردازش مطابق همان فایل را پیدا می‌کند. اگر پیدا نکرد، «پیدا کردن پردازش» را بزن. اگر چند مورد دیدی، مورد آزمایشی درست را انتخاب کن.

۳. دو تأیید محیط آزمایشی و خصوصی‌بودن لاگ را بخوان؛ فقط اگر واقعاً برقرارند، تیک بزن. برای ذخیرهٔ بدنهٔ درخواست‌ها، گزینهٔ اختیاری بدنه را هم انتخاب کن. سپس **«۲. شروع بررسی»** و تأیید نهایی را بزن.

۴. حدود **۳۰ ثانیه** صبر کن؛ ابزار برای توقف و جداشدن دیباگر تلاش می‌کند. زودتر هم می‌توانی «توقف امن» را بزنی. بعد از پایان، نتیجه خودش خوانده می‌شود:
- **«دیدن URLهای خصوصی، فقط محلی»**: نشانی‌های احتمالی با مسیر/query، فقط برای خودت.
- **«باز کردن گزارش قابل‌اشتراک»**: فایل Report-to-share.json؛ فقط همین فایل را برای بررسی بفرست.

اگر CDB خودکار پیدا نشد ولی نصب است، با «انتخاب CDB در صورت نیاز» فایل cdb.exe نسخهٔ x64 را انتخاب کن. اگر مشکل امضا/مجوز/محافظت بود، حفاظت یا ضدتقلب را غیرفعال نکن.

## اگر توقف تأیید نشد

دکمهٔ **«راهنمای توقف دستی»** فرمان لازم را کپی می‌کند. فقط در پنجرهٔ CDB همین ابزار، Ctrl+C بزن؛ سپس فرمان کپی‌شده را بچسبان و Enter بزن. فقط q نزن و دیباگر را با زور نبند. ابزار برای توقف، برنامهٔ هدف را force-kill نمی‌کند.

## مهم

- اگر محیط آزمایشی جداگانه نداری، این کیت را روی بازی اجرا نکن. تیک‌های رابط صرفاً تأیید تو هستند، نه تشخیص فنی محیط.
- این نسخه روی بازی آزمایش نشده و استخراج URL/بدنه تضمین نیست؛ HTTP/2 و HTTP/3، فشرده‌سازی و protobuf تفسیر نمی‌شوند.
- دیدن داده در ورودی EncryptMessage، اثبات ارسال به سرور نیست.
- لاگ خام حتی بدون انتخاب گزینهٔ بدنه ممکن است رمز، توکن، Cookie یا اطلاعات شخصی داشته باشد. فایل‌های PRIVATE، لاگ و بدنه را عمومی یا روی GitHub منتشر نکن.
- ابزار فایل EXE هدف را خودکار اجرا نمی‌کند و فرزندان پردازش را دنبال نمی‌کند.
