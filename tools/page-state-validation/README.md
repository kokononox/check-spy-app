# Query-only owned page-state validation

Queries VirtualQueryEx metadata and module information. No process content reader, code dump, protection modification, debugger or injection in the tool. Native tests allocate and change only pages belonging to the test process itself to distinguish committed, guard, no-access and reserved states. No user game files, game hashes/RVAs or private reports are published here. Passing tests does not establish actual game compatibility or any outgoing hardware payload.
