# تغییرات نسخهٔ ۰.۳

- صفر درخواست دیگر به معنی نبود ارسال نمایش داده نمی‌شود.
- خطای برنامه و توقف احتمالی در رابط و گزارش امن مشخص می‌شوند.
- درخواست breakpoint، فهرست و حالت deferred آن، ورود handler و بافرهای ثبت‌شده جدا هستند.
- نتیجهٔ helper توقف، مرحلهٔ شکست و وضعیت همان نسل پردازش هدف بعد از خروج دیباگر گزارش می‌شوند؛ موفقیت قطعی detach ادعا نمی‌شود.
- گزارش تا پایان helper صبر می‌کند؛ خطاها خودکار رد نمی‌شوند.

این اصلاح، مشکل تشخیص وضعیت را حل می‌کند؛ هنوز URL یا بدنهٔ ثبت‌نشده را از هیچ تولید نمی‌کند. روی بازی و حساب واقعی آزموده نشده است.
