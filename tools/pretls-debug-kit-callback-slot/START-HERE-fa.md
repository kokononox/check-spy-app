# راه ساده — نسخهٔ ۰.۸، ثبت محدود مقصد احتمالی

این مرحله برخلاف استخراج آفلاین، به یک نشست تازه نیاز دارد. CDB قبلی کافی است؛ دوباره نصب نکن. فقط Windows x64.

۱. ZIP را در **پوشهٔ جدید** استخراج کن؛ فایل‌های نسخه‌های قبلی را روی آن نریز. **Start.cmd** را باز کن.

۲. EXE برنامهٔ مجاز را انتخاب کن. فقط اگر برنامه از قبل در **محیط آزمایشی جداگانه، بدون حساب واقعی و بدون جلسهٔ آنلاین ضدتقلب** اجرا شده، دو تأیید را تیک بزن و **«۲. اتصال و بررسی آغاز»** را بزن. اگر این محیط را نداری، اجرا نکن.

۳. **دکمهٔ «۳. ادامهٔ اولیه» را نزن. هیچ فرمان g/gn وارد نکن.** ابزار پس از اطلاعات آغاز، یک‌بار ثبت محدودِ مقصد احتمالی را تلاش می‌کند. حدود **۶۰ ثانیه** منتظر پایان بررسی و تلاش برای توقف امن بمان. پایان ممکن است بیشتر طول بکشد؛ زمان ضمانت توقف در همهٔ خطاها نیست.

۴. **«باز کردن گزارش قابل‌اشتراک»** را بزن و فقط **Report-to-share.json جدید** را بفرست. ابزار آفلاین RVA را برای این مرحله دوباره اجرا نکن.

## چه چیزی تازه است؟

فقط در توقف اولیهٔ breakpoint واجد شرایط، با تطبیق هش loader، محل توقف، آدرس بازگشت، نخ جاری و stack pointer فریمِ فراخواننده، یک خانهٔ ۸‌بایتی stack خوانده می‌شود. آدرس هدف احتمالی فقط به دستهٔ ماژول و RVA تبدیل می‌شود. به مقصد پرش نمی‌کنیم، آن را اجرا نمی‌کنیم و حافظهٔ هدف یا فیلتر خطا را تغییر نمی‌دهیم.

.frame فقط زمینهٔ محلیِ دیباگر را برای بررسی فریم عوض می‌کند و بازگشت به فریم صفر درخواست می‌شود. صحت unwind و این‌که مقدار همان مقصد واقعیِ call بوده باشد تضمین نیست. این روش روی نمونهٔ خود کیت آزموده شده، نه بازی. اگر فریم/هش/محل توقف تطبیق نداشته باشد، ثبت رد می‌شود؛ حفاظت را برای موفقیت غیرفعال نکن.

CallbackSlot.CandidatePoint در گزارش ممکن است null باشد: یعنی مقصد قابل‌تطبیق ثبت نشده است؛ نه نبود ارسال یا نبود فراخوانی. URL و بدنهٔ شبکه هنوز تضمین‌شده نیستند.

## اگر پایان تأیید نشد

از **«راهنمای توقف دستی»** داخل رابط استفاده کن؛ فقط پنجرهٔ CDB همین نشست. فقط q نزن و هدف/دیباگر را با زور نبند. تیک‌ها تأیید تو هستند، نه بررسی واقعی جداسازی سیستم.

لاگ خام، آدرس‌ها، فایل‌های PRIVATE و body ممکن است اطلاعات حساس داشته باشند؛ آن‌ها را نفرست و روی GitHub منتشر نکن. تنظیم CallbackTarget-local.json اختصاصی همین بررسی است؛ آن را تغییر نده یا روی مخزن عمومی منتشر نکن.
