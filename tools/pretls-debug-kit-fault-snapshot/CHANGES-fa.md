# تغییرات ۰.۵

- آغاز نشست و ادامهٔ اولیهٔ صریح نسخهٔ ۰.۴ حفظ شد.
- ثبت خودکار و یک‌بارهٔ .lastevent/.exr برای first-chance AV پس از ادامهٔ اولیه اضافه شد.
- نوع ثبت‌شدهٔ خواندن، نوشتن یا اجرا به گزارش امن اضافه شد؛ آدرس/پارامتر خام صادر نمی‌شود.
- helper جدید نه interrupt دارد، نه g/gn، نه force-kill و نه تغییر فیلتر استثنا.
- گزارش تا پایان helper خواندن صبر می‌کند؛ درخواست stop هنگام کار helper بعد از پایان آن می‌تواند انجام شود.
- آزمون جدید CDB روی fixture native متعلق به کیت با exception record عمداً Raise‌شده موفق شد؛ نوع Execute ثبت شد، بدون ادامه از خطا قبل از درخواست stop. هدف خود CI پس از پایان debugger زنده ماند.

این نسخه ابزار تشخیص مانع است، نه وعدهٔ استخراج کامل URL/بدنه. بازی یا ارسال شبکه آزموده نشده است.
