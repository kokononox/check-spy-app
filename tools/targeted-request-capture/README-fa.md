# ضبط هدفمند درخواست‌ها — نسخهٔ آزمایشی ۱.۰

## ابتدا این هشدار را بخوان
این ابزار از Frida برای اتصال و ابزارگذاری موقت فرایند انتخاب‌شده استفاده می‌کند. ابزارگذاری می‌تواند شامل تغییر موقت کد در حافظه باشد؛ این ابزار «فقط خواندن حافظه» نیست. ممکن است برنامه بسته شود، ضدتقلب آن را نپذیرد یا طبق قوانین بازی حساب محدود شود. فقط در محیطی استفاده کن که این کار مجاز است؛ اگر دربارهٔ حساب اصلی یا ضدتقلب مطمئن نیستی، اجرا نکن. ابزار هیچ ضدتقلبی را دور نمی‌زند و در صورت شکست اتصال، آدرس حدسی یا راه افزایش دسترسی امتحان نمی‌کند.

## این بسته چه کار می‌کند؟
به فرایندی که خودت انتخاب می‌کنی متصل می‌شود و فقط APIهای دارای export شناخته‌شده را بررسی می‌کند:
- WinHTTP: ساخت نشانی درخواست، SendRequest و WriteData.
- OpenSSL: ورودی SSL_write و SSL_write_ex، در صورت موجود بودن export.
- SSPI: بافرهای دادهٔ ورودی EncryptMessage. مشاهدهٔ این API به‌تنهایی ثابت نمی‌کند ارتباط TLS بوده است.

این روش به‌جای شکستن HTTPS، ورودی بعضی APIهای ارتباطی را مشاهده می‌کند. استخراج کلید جلسه پیاده‌سازی نشده است. اگر کتابخانهٔ بازی استاتیک، پنهان یا سفارشی باشد، ممکن است هیچ محتوایی ثبت نشود. کار کردن ابزار روی این بازی هنوز تأیید نشده است.

## به ترتیب چه کار کنم؟
۱. تمام ZIP را در یک پوشهٔ جدید از حالت فشرده خارج کن؛ داخل ZIP اجرا نکن. نصب Python، CDB یا Frida لازم نیست؛ وابستگی‌ها داخل بسته‌اند. ویندوز ۶۴بیتی لازم است.
۲. فقط اگر ابزارگذاری طبق شرایط بالا مجاز است، بازی را معمولی اجرا کن و فعلاً در صفحهٔ ورود بمان. ابزار نباید برای دور زدن محدودیت بازی استفاده شود.
۳. START.cmd را دوبار کلیک کن. هشدار را بخوان؛ اگر قبول داری، YES بنویس و Enter بزن.
۴. از فهرست، شمارهٔ فرایند خود بازی را وارد کن؛ لانچر، مرورگر یا Python ابزار را انتخاب نکن. نام انتخاب را با YES تأیید کن.
۵. ضبط حداکثر ۱۲۰ ثانیه از زمان اتصال ادامه دارد. رویدادهای قبل از اتصال ثبت نمی‌شوند. ابتدا چند ثانیه در صفحهٔ ورود بمان. اگر تصمیم داری وارد شوی، هنگام شروع ورود کلید 2 را بزن؛ پس از ورود کلید 3 را بزن. این علامت‌ها دستی‌اند و تشخیص خودکار ورود نیستند.
۶. برای پایان زودتر Q را بزن یا منتظر پایان ضبط بمان. پوشهٔ Results ایجاد می‌شود. پنجره بعد از خطا خودکار بسته نمی‌شود.

## کدام فایل را بفرستم؟
فقط **Report-to-share.json** از جدیدترین پوشهٔ Results را بفرست.

فایل‌های زیر را عمومی یا خودکار ارسال نکن:
- PRIVATE-URLs.txt: نشانی‌های کامل ثبت‌شده؛ ممکن است token یا شناسه در URL باشد.
- PRIVATE-requests.json: بدنهٔ درخواست‌ها به‌صورت Base64؛ Base64 رمزگذاری امنیتی نیست و ممکن است رمز ورود، کوکی، توکن یا دادهٔ شخصی داشته باشد.
- PRIVATE-events.jsonl: ورودی‌های خام APIها؛ ممکن است حساس باشند.
- PRIVATE-error.txt: در صورت خطا، جزئیات محلی.

همهٔ این فایل‌ها فقط روی سیستم خودت نوشته می‌شوند؛ ابزار هیچ آپلودی انجام نمی‌دهد. خود بازی ممکن است طبق رفتار معمول خود شبکه استفاده کند. گزارش قابل‌اشتراک URL کامل، بدنه، رمز یا مقدار مشخصات سیستم را شامل نمی‌شود؛ فقط مبدأ مقصد، شمارش‌ها و نام برخی فیلدهای شبیه مشخصات سخت‌افزار را گزارش می‌کند. این نام‌ها به‌تنهایی معنای مقدار یا ارسال قطعی آن را ثابت نمی‌کنند.

## نتیجه‌ها را اشتباه تعبیر نکن
- Hook available: آن API قابل اتصال بود، نه اینکه بازی از آن استفاده کرده است.
- Plaintext input observed: یک بافر ورودی API مشاهده شد، نه اینکه سرور آن را دریافت کرده است.
- API accepted: API پذیرش داده را اعلام کرده؛ هنوز رسیدن به سرور اثبات نشده است.
- NoPlaintextObserved: ابزار چیزی ندید؛ به معنای «برنامه اطلاعات ارسال نمی‌کند» نیست.

نشانی WinHTTP از پارامترهای ساخت درخواست به دست می‌آید؛ تغییر مسیر/redirect مقصد نهایی ثبت نمی‌شود. رمز و هدرهای Authorization عمداً در گزارش اشتراکی نیستند. بدنه‌های JSON و برخی بدنه‌های gzip JSON بررسی می‌شوند. HTTP/2، chunked، protobuf باینری و قالب رمزگذاری سفارشی در این نمونه رمزگشایی/تفسیر نشده‌اند. ورودی‌های ثبت‌شده ممکن است ناقص باشند و فراخوانی‌های تو در تو داده را تکرار کنند. هر بافر حداکثر ۶۴ کیلوبایت و کل ضبط حداکثر ۲۰ مگابایت است.

## اگر اتصال یا ضبط شکست خورد
توقف کن؛ لازم نیست محافظت، اعتبارسنجی TLS یا ضدتقلب را خاموش کنی، گواهی نصب کنی یا ابزار را با دسترسی بالاتر دوباره امتحان کنی. Report-to-share.json فقط علت کلی و دامنهٔ مشاهده را مشخص می‌کند. موفقیت تست ساختگی ویندوز هم تضمین سازگاری با بازی نیست.
